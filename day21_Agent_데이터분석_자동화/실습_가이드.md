막히면 각 항목의 **힌트**와 **정답 노트북**을 참고하세요.

> **본인 OpenAI API 키가 필요합니다.** 14일차부터 쓰던 그 키를 그대로 씁니다. 에이전트가 **실제로**
> 모델을 호출해 도구를 고르고 계획을 세웁니다. 오늘 오가는 요청은 짧은 분석 질문 수십 건이라 비용은 아주 적습니다.
> **키가 없으면 각 노트북의 준비 셀이 안내와 함께 그 자리에서 멈춥니다.** 우회 경로는 없습니다.

## 1. 교안_01: MCP 클라이언트 (`교안_01_MCP_클라이언트/`)

지금까지 도구는 전부 우리가 만들었습니다. 여기서는 **남이 만들어 공개한 MCP 서버**에 붙여 씁니다.
서버 제작은 다루지 않습니다. 이 파트는 **`.py` 와 `.ipynb` 가 함께** 들어 있습니다. 맥·리눅스에서는
노트북으로 그대로 진행하면 되고(따라하기가 노트북에만 있습니다), 윈도우 주피터는 MCP 서버 프로세스를
띄우지 못하니 `.py` 로 진행하세요(자세한 이유는 폴더의 `README.md`).

> 실행은 그 파일이 있는 폴더에서 `uv run <파일이름>` 입니다.
> 각 파일은 `async def main()` 하나와 맨 아래 `asyncio.run(main())` 로 되어 있습니다.
> 준비물: `OPENAI_API_KEY` · 인터넷 · `npx`(Node.js) · `uvx`(uv) · 05 번은 크로미움(`npx playwright install chromium`).
> 첫 실행은 서버를 내려받느라 느립니다.

- [ ] **교안_01_MCP_클라이언트/교안_01_MCP_개념.ipynb**: 읽기 자료. MCP 가 왜 필요한가 · MCP 는 무엇인가 · 호스트/클라이언트/서버 · 전송 방식(stdio·HTTP) · 우리 `@tool` 과의 차이.
- [ ] **01_파일시스템_MCP.py**: 파일시스템 서버에 붙어 도구 목록 받기 · 명세(name·description·args) 읽기 · 직접 호출 · 반환값에서 text 뽑기(`result[0]["text"]`) · 에이전트에 붙이기 · 동기 호출이 막히는 것 확인.
- [ ] **02_웹검색_MCP.py**: 검색 도구 직접 호출 · 본문 가져오기 · 에이전트가 스스로 검색해 3문장 요약.
- [ ] **03_브라우저조작_Playwright.py**: 브라우저 서버 연결(도구 20여 개) · 페이지 열기 · 스냅샷으로 화면 구조 읽기 · 낱말 찾기 · 세션을 열어 두는 이유 · 필요한 도구만 골라 에이전트에 넘기기.
- [ ] **04_SQLite_MCP.py**: DB 서버 연결(읽기·쓰기 도구가 함께 온다) · 스키마부터 보기(`list_tables`·`describe_table`) · `read_query` 로 SELECT · 읽기 도구만 골라 붙인 에이전트가 스스로 SQL 쓰기.
- [ ] **05_코드실행_MCP.py**: 코드를 문자열로 보내 실행 · 여러 줄 코드 · 모델이 스스로 코드를 짜서 통계 계산.
- [ ] **06_종합_데이터분석_자동화.py**: 서버 3개를 한 클라이언트에(`tool_name_prefix`) · DB 결과를 코드 실행 도구로 넘기는 인계 두 관문(자료형·프로세스 경계) · 그래프를 그려 PNG 로 저장 · 질문 한 문장에서 리포트 파일까지 · 서버가 안 뜰 때.
- [ ] **과제/**: 문제마다 파일 하나입니다(`문제1_도구목록과_호출.py` ~ `문제4_체인코드_만들기.py`). 도구 목록·명세·직접 호출 → 코드 실행 서버를 에이전트에 붙이기 → 원격 HTTP(Context7) 서버를 에이전트에 붙이기 → 문서조회+코드실행+우리 도구로 LangChain 기초 체인 코드 만들기. 파일마다 자가채점이 있고 통과하면 "문제 N 통과" 가 찍힙니다. 서버 설정은 `과제/공통.py` 가 제공합니다.

### 이 파트에서 막혔을 때

- `npx`·`uvx` 를 찾을 수 없다는 에러가 나면 Node.js 또는 uv 를 설치하고 **터미널(VS Code)을 새로 연 뒤** 다시 실행하세요.
- 05 번에서 브라우저를 못 찾는다는 에러가 나면 `npx playwright install chromium` 을 한 번 실행하세요.
- 서버가 안 뜨거나 응답이 없으면 터미널에 섞여 나오는 **서버 로그**를 보세요. 서버는 우리가 띄운 자식 프로세스라 화면을 같이 씁니다.
- `NotImplementedError: StructuredTool does not support sync invocation`: MCP 도구를 `invoke` 로 불렀다는 뜻입니다. `await 도구.ainvoke({...})` 로 부르세요.
- 결과가 `[{'type': 'text', ...}]` 처럼 보이면 정상입니다. 사람이 읽을 값은 교안 `.py` 에서는 `result[0]["text"]` 로, 노트북과 과제에서는 `block_text(result)` 로 꺼냅니다(`block_text` 는 에러가 문자열 하나로 오는 경우까지 받아 냅니다).
- 검색·문서조회는 외부 서비스라 **같은 질문에도 결과가 조금씩 다릅니다.** 자가채점은 그래서 내용이 아니라 형태(길이·링크 포함 여부)만 봅니다.
- `RateLimitError ... tokens per min` 은 분당 토큰 한도입니다. 도구가 많을수록 도구 설명이 매 요청에 실려 토큰이 커집니다. **1분쯤 기다렸다가 다시 실행**하세요.
- 코드 실행 도구는 **표준 출력만** 돌려줍니다. 값만 적은 코드는 빈 결과가 오니 `print(...)` 로 출력하세요.

## 오늘 과제는 두 갈래입니다

두 과제가 겹쳐 보이지만 맡은 곳이 다릅니다. 앞부분(서버 연결·도구 호출)이 비슷한 것은 일부러입니다.
`.py` 로 익힌 것을 노트북 관용구로 한 번 더 해 보는 워밍업입니다.

| 과제 | 맡은 곳 | 형식과 관용구 |
| --- | --- | --- |
| `교안_01_MCP_클라이언트/과제/` | **직접 호출에서 에이전트로**: 원격 HTTP(Context7)·코드 실행·우리 `@tool` 을 에이전트에 붙인다 | `.py`, `async with client.session(...)`, `result[0]["text"]` |
| `교안_02_계획_실행_자동화/과제/` | **계획과 파이프라인**: 훅 자리 → 계획 → 조회·계산·그래프·리포트 → 정형화 | `.py`, `tool_name_prefix=True`, `result.get("todos", [])` |

권장 순서: 교안_01 → `교안_01.../과제/` 문제 1~4 → 교안_02 → `교안_02.../과제/` 문제 1~4.

## 부록 (수업에서 다루지 않음)

**완주 기준에 들어가지 않는 참고 자료**입니다. 필요할 때 열어 보세요.

- **`부록_동기_비동기_기초.ipynb`**: 코드에서 **`async`·`await`** 를 만났을 때. 동기 실행이 왜 3초인지부터
  시작해 **코루틴**의 정의(멈췄다가 그 줄부터 이어 가는 함수), `async def` 가 돌려주는 코루틴 객체,
  `await`, `asyncio.gather`(3초 → 1초), 비동기가 부르는 쪽으로 전염되는 것, 주피터와 `.py` 에서 시작하는
  방법이 왜 다른지, 어디에 쓰고 어디에 쓰지 않는지까지 훑습니다. 끝의 두 절에서 **동시 호출 수 제한**(`asyncio.Semaphore`)과 **LangChain 의 `ainvoke`·`abatch`** 를 다루는데, 마지막 절만 실제 모델을 부르므로 `OPENAI_API_KEY` 가 필요합니다.

## 막혔을 때

- `NotImplementedError: StructuredTool does not support sync invocation` 은 MCP 도구를 `invoke` 로 불렀다는 뜻입니다. 도구는 `await 도구.ainvoke({...})`, 에이전트는 `await 에이전트.ainvoke({...})` 로 부르세요.
- 결과가 `[{'type': 'text', ...}]` 처럼 보이면 정상입니다. 사람이 읽을 값은 **`block_text(결과)`** 로 뽑습니다. 문자열인 줄 알고 `.split` 을 부르면 그 자리에서 터집니다.
- 답이 `Model call limits exceeded` 로 끝나면 호출 상한에 걸린 것입니다. 대개 **셀을 다시 실행**하면 됩니다. 자주 걸리면 `run_limit` 을 올려 보세요.
- 코드 실행 도구가 **빈 결과**를 돌려주면 `print` 를 빠뜨린 것입니다. 이 서버는 표준 출력만 돌려줍니다(경고가 하나라도 나면 그 출력마저 버립니다).
- `npx`·`uvx` 를 찾을 수 없다는 에러가 나면 Node.js 또는 uv 를 설치하고 **터미널(VS Code)을 새로 연 뒤** 커널을 재시작하세요.
- `RateLimitError ... tokens per min` 은 분당 토큰 한도입니다. 도구가 많을수록 도구 설명이 매 요청에 실립니다. **1분쯤 기다렸다가** 다시 실행하세요.
- 준비 셀에서 `OPENAI_API_KEY 를 찾지 못했습니다` 가 뜨면 `.env` 를 만들었는지, 키를 채웠는지 확인하고 **커널을 재시작**한 뒤 그 셀부터 다시 실행하세요.
- 도구가 뜻대로 안 불리면, 도구의 **docstring(설명)** 이 질문의 표현과 맞는지 살펴보세요. 에이전트는 설명을 읽고 도구를 고릅니다.
- `todos` 가 안 보이면, 질문이 **여러 단계**인지(복합 요청) 확인하세요. 단순 질문은 계획을 세우지 않습니다.

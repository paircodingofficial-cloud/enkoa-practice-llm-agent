## 실행 전에 확인할 것

- 정답 노트북은 각 일차 폴더의 `data/`·`images/` 와 `.env` 를 그대로 읽습니다(예: `../../day14_OpenAI_API_활용/data/...`). 저장소 폴더 구조를 유지한 채 열어야 경로가 맞습니다.
- 산출물은 노트북과 같은 폴더의 `output/` 에 만들어집니다.
- 대부분 실제 API 호출이 필요합니다. 각 일차의 `.env.example` 을 `.env` 로 복사해 본인 키를 채우세요(키는 코드에 직접 적지 마세요).
- `day21` 정답은 `.py` 파일입니다. 파일이 있는 폴더에서 `uv run 문제1_도구목록과_호출_정답.py` 처럼 실행하고, 설정은 실습 폴더의 `공통.py` 를 그대로 씁니다.

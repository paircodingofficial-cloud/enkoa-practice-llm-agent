# 에이전트 품질·관측성 실습 진행 가이드

이 체크리스트를 위에서부터 따라가면 오늘 실습을 빠짐없이 완주할 수 있습니다.
막히면 각 항목의 **힌트**와 **정답 노트북**을 참고하세요.

> **본인 OpenAI API 키가 필요합니다.** 지금까지 쓰던 그 키입니다. `.env.example` 을 `.env` 로
> 복사해 `OPENAI_API_KEY` 를 채우세요. 키가 없으면 준비 셀이 안내와 함께 멈춥니다.
> 오늘 배우는 **토큰·지연 같은 관측값은 실제 호출에서만 나옵니다.** 그래서 이 일차는 우회로 없이 실제 API 로만 진행합니다.
> **Langfuse 키(`LANGFUSE_*`)도 필요합니다.** 관측성은 대시보드에 기록이 쌓이는 것을 직접 봐야 배울 수 있어
> 전송을 끄면 그 단원이 성립하지 않습니다. [cloud.langfuse.com](https://cloud.langfuse.com) 에서
> **무료로 가입**(신용카드 불필요)한 뒤 프로젝트를 만들고 **Settings → API Keys** 에서 public·secret 키를
> 복사해 `.env` 에 채우세요. 무료 한도(월 5만 건)로 이 수업은 충분합니다.
> 교안_03 에서는 실행 기록(**Tracing → Traces**)뿐 아니라 **프롬프트를 서버에 올리고 불러옵니다.** 그래서 왼쪽 메뉴의
> **Prompts** 탭도 함께 씁니다. 본인이 만든 프로젝트라면 **Owner** 권한이라 별도 설정 없이 쓸 수 있고,
> 남이 만든 프로젝트에 초대받아 들어간 경우에는 **Viewer 가 아닌 Member 이상**이어야 프롬프트를 올릴 수 있습니다.
> 가입부터 `.env` 채우기까지 단계별 설명은 [Langfuse 키 발급 가이드](Langfuse_키_발급_가이드.md)에 있습니다.

**노트북**(`교안_01_계획_실행_자동화.ipynb`)에서 읽습니다.

- [ ] **1. 계획 없는 에이전트의 한계**: 복합 요청을 계획 없이 시켰을 때 단계를 놓치는 것을 관찰.
- [ ] **2. 미들웨어**: 에이전트 루프에 기능을 덧붙이는 확장 장치. **훅 여섯 자리**와 각 자리에 주로 무엇을 거는지, `before_`/`after_` 와 `wrap_` 의 차이, 여러 개를 끼울 때의 순서. **어느 미들웨어가 어느 자리를 쓰는지 셀에서 직접 확인**(모델을 부르지 않습니다).
- [ ] **3. `TodoListMiddleware`**: **Plan-and-Execute**(계획 수립 → 단계 실행)를 미들웨어 한 줄로 얻기. `write_todos` 로 계획을 세우고 `result['todos']` 로 상태 확인. 개념도 `images/react_vs_plan_execute.png`.

**실습 `.py`** 는 이 폴더에서 `uv run <파일 이름>` 으로 하나씩 돌립니다(자세한 안내는 폴더의 `README.md`).

- [ ] `01_프롬프트_비교_그래프저장.py`: 같은 질문에 프롬프트만 바꿔 두 번 돌려 **도구 선택이 갈리는 것**을 확인. 파일 크기와 PNG 서명까지 본다.
- [ ] `02_계획_세우기_TodoList.py`: 계획(todos)을 세우고 단계별로 처리하는 것을 기록으로 확인.
- [ ] `03_자동_분석_파이프라인.py`: 조회(`db_read_query`) → 계산(`code_run-code`) → 그래프(`code_run-code`) → 리포트(`files_write_file`)를 한 번에.
- [ ] `04_구조화된_출력.py`: `create_agent(response_format=...)` 로 답을 처음부터 틀에 받아 표·JSON 으로 적재. 값과 근거 SQL 을 한 행에 함께 쌓는다.

## 3. 교안_03: 관측성과 운영 견고성

폴더 `교안_03_관측성과_운영_견고성/` 안에서 진행합니다. 노트북 하나로 여섯 절을 이어 갑니다.

- [ ] **3. 토큰·비용 읽기**: `usage_metadata` 로 전체·출력 토큰 집계. 따라하기·퀴즈.

- [ ] **6. 실패를 추적하는 워크플로**: `tool_trace` 도우미, **모호한 도구 설명으로 라우팅을 일부러 틀어 보고**(6.1) **설명만 고쳐 다시 돌려**(6.2) 불린 도구 목록이 달라지는 것을 확인. 두 실행 모두 `handlers` 를 붙이므로 **같은 메시지 기록을 Langfuse 대시보드에서도** 열어 비교한다. 퀴즈.

# 교안_03: 관측성과 디버깅

이 단원은 **노트북 하나로 끝까지** 진행합니다. 에이전트 안에서 무슨 일이 있었는지 알아내는
**관측성**을 Langfuse 로 다룹니다. 실행을 대시보드에 남기고, 토큰과 비용을 직접 계산해 서버 값과 맞춰 보고,
프롬프트를 버전으로 관리하고, 여러 호출을 세션으로 묶고, 마지막으로 기록을 읽어 틀어진 답을 고칩니다.

`교안_03_관측성과_디버깅.ipynb` 를 열어 위에서부터 실행하세요.

## 다루는 것

| 절 | 무엇 | 핵심 |
|---|---|---|
| 1 | 관측성의 개념과 목적 | 로그·지표·트레이스, 모니터링과의 차이, Langfuse 와 LangSmith |
| 2 | Langfuse 구조와 연동 | trace → span → generation, `config={'callbacks': handlers}` |
| 3 | 토큰과 비용 | `usage_metadata` 로 읽고, 100만 토큰당 단가로 계산해, `trace.total_cost` 와 대조 |
| 4 | 프롬프트를 코드 밖에서 관리 | `data/prompts.yaml` 로 감 잡기 → `create_prompt`·`get_prompt`·라벨·버전 연결 |
| 5 | 세션으로 묶기 | `metadata={'langfuse_session_id': 값}` 으로 대화 한 판 만들기 |
| 6 | 실패를 추적하는 워크플로 | 메시지 기록으로 라우팅 확인, 도구 설명을 고쳐 다시 돌리기 |

## 준비물

- **`OPENAI_API_KEY`**: 일차 폴더(`day22_에이전트_품질_관측성`)의 `.env` 에 채웁니다.
- **`LANGFUSE_PUBLIC_KEY`·`LANGFUSE_SECRET_KEY`·`LANGFUSE_BASE_URL`**: 같은 `.env` 에 채웁니다.
  발급 절차는 일차 폴더의 [Langfuse 키 발급 가이드](../Langfuse_키_발급_가이드.md)에 있습니다.

토큰·지연·비용 같은 **관측값은 실제 호출에서만** 나옵니다. 그래서 이 단원은 우회로 없이 실제 API 로 진행합니다.

## 대시보드에서 볼 곳

노트북을 실행하는 동안 [cloud.langfuse.com](https://cloud.langfuse.com) 을 함께 열어 두세요.

- **Tracing → Traces**: 실행 한 건이 trace 로 쌓입니다. 열면 단계별 시간·토큰·비용이 보입니다.
- **Tracing → Sessions**: 5절에서 붙인 이름표로 대화가 한 줄로 묶입니다.
- **Prompts**: 4절에서 올린 프롬프트가 버전과 라벨을 달고 쌓입니다.

## 과제

`과제/과제_관측성과_디버깅.ipynb` 한 권입니다. 노트북을 마친 뒤 푸세요.
문제 일곱 개가 이 단원을 한 번씩 훑습니다.

| 문제 | 무엇을 훈련하나 |
|---|---|
| 1 | 관측 콜백 붙이기 |
| 2 | 여러 호출의 토큰 모으기 |
| 3 | 공식 요금표로 비용 계산 |
| 4 | 서버가 계산한 비용과 맞춰 보기 |
| 5 | 프롬프트를 서버에 올리고 라벨로 불러오기 |
| 6 | 대화 한 판을 세션으로 묶기 |
| 7 | 기록을 읽고 라우팅 고치기 |

도메인은 교안(온라인 강의)과 다른 **헬스장 회원권**입니다. 데이터는 일차 폴더의 `data/gym_members.csv` 입니다.

## 막혔을 때

- `OPENAI_API_KEY 를 찾지 못했습니다` 가 뜨면 일차 폴더에 `.env` 를 만들었는지 확인하세요.
- `Langfuse 인증에 실패했습니다` 는 키는 있으나 값이 틀렸다는 뜻입니다. 키를 다시 복사하고,
  가입한 지역의 주소가 `LANGFUSE_BASE_URL` 에 들어 있는지 보세요.
- 셀은 통과했는데 대시보드가 비어 있으면, 전송에 몇 초 걸리니 새로고침하고 화면 왼쪽 위에서
  키를 발급한 프로젝트가 선택돼 있는지 확인하세요.
- 서버에서 되읽는 셀(3.3·과제 4·6번)이 오래 걸리는 것은 정상입니다. 지연을 기다리는 코드입니다.
- 4절에서 프롬프트 업로드가 막히면 그 프로젝트에서의 권한이 Viewer 인지 확인하세요. Member 이상이어야 합니다.

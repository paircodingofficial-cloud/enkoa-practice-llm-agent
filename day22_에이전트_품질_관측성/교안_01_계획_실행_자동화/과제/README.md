# 교안_01 과제: 계획을 세우고 파이프라인으로 자동화하기

교안_01 에서 본 순서를 문제 세 개로 나눠 직접 만들어 봅니다.
파일마다 `# 여기에 코드를 작성하세요` 자리를 채우고 실행하면 `# [자가채점]` 이 답을 검사합니다.
통과하면 "문제 N 통과" 가 찍히고, 아직 안 푼 문제에서 멈추는 것이 정상입니다.

| 파일 | 무엇 | 모델 호출 |
|---|---|---|
| `문제1_계획_에이전트.py` | TodoListMiddleware 로 복합 요청에 계획을 세우게 하기 | 있음 |
| `문제2_분석_파이프라인.py` | 조회 → 계산 → 그래프 → 리포트를 한 번에 시키기 | 있음 |
| `문제3_결과_정형화.py` | 자유 문장 답을 정해진 틀에 담아 JSON 으로 적재하기(db 서버만) | 있음 |
| `공통.py` | 서버 설정·경로·허용 도구 목록·공통 시스템 프롬프트 | 제공 |
| `정답/` | 문제별 정답 | 강사용 |

## 실행 방법

이 폴더에서 파일 이름만 주면 됩니다.

```bash
uv run 문제1_계획_에이전트.py
```

번호 순서대로 푸세요. 문제 1 에서 만든 계획 에이전트를 문제 2 에서 그대로 다시 씁니다.

세 문제 모두 모델을 부릅니다. 한 문제에 수십 초에서 몇 분이 걸리고, 서버를 처음 받는 첫 실행은 더 걸립니다.
중간에 실패하면 그냥 다시 실행하면 됩니다. 문제 2·3 은 맨 앞에서 지난 산출물을 지우고 시작합니다.

문제 3 은 DB 조회만 하므로 **db 서버 하나만** 띄웁니다. 코드 실행 서버까지 붙이면 모델이 SQL 대신
그 안에서 sqlite3 로 DB 에 붙으려다 실패를 되풀이하다 호출 상한에서 끝납니다.

문제 3 에서 `계획을 세우지 않았습니다` 로 멈추면 코드가 틀린 것이 아닐 수 있습니다.
한 단계로 끝나는 질문이라 모델이 `write_todos` 를 건너뛰는 실행이 가끔 있습니다.
`TodoListMiddleware()` 를 넘겼는데도 그 줄에서 멈추면 그대로 다시 실행하세요.

## 산출물이 생기는 곳

문제 2·3 이 만드는 그래프·리포트·JSON 은 모두 이 폴더의 `output/` 에 모입니다.
`공통.py` 가 두 가지를 맞춰 두기 때문입니다.

- 파일시스템 서버에는 **`output/` 폴더**를 허용 폴더로 준다(그 밖은 건드리지 못한다).
- 코드 실행 서버에는 같은 폴더를 **작업 폴더(`cwd`)** 로 준다.

두 서버가 상대경로를 푸는 기준이 원래는 서로 다릅니다. 파일 서버는 **열어 준 폴더**가,
코드 실행 서버는 **작업 폴더**가 기준입니다. 둘을 같은 폴더로 맞춰 두었으므로
에이전트에게는 `장르별_매출.png` 처럼 **파일 이름만** 시키면 됩니다.

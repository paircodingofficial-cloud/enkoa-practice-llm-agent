## 시작하기

### 1. 환경 만들기 — uv

이 저장소는 [uv](https://docs.astral.sh/uv/) 로 파이썬 환경을 관리합니다. `pyproject.toml`·`uv.lock` 이
들어 있으므로 **명령 한 줄이면 수업과 똑같은 환경**이 만들어집니다.

```bash
# uv 가 없다면 먼저 설치 (macOS·Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 저장소를 받은 폴더에서
uv sync            # .venv 생성 + 잠긴 버전 그대로 설치
```

### 2. 주피터 실행

```bash
uv run jupyter lab
```

커널은 **Python 3 (ipykernel)** 을 고릅니다. VS Code 를 쓴다면 오른쪽 위 커널 선택에서
이 폴더의 `.venv` 를 고르세요.

### 3. (선택) 본인 API 키 넣기

**키가 없어도 실습은 그대로 진행됩니다.** 각 일차 폴더에 저장해 둔 응답(`data/api_cache.json`)이
재생되기 때문입니다. 준비 셀을 실행했을 때 `오프라인 캐시 응답 모드` 가 뜨면 정상입니다.

본인 키로 **실제 응답**을 받아 보려면 일차 폴더 안에서:

```bash
cp .env.example .env      # 그리고 .env 를 열어 OPENAI_API_KEY 를 채웁니다
```

`오프라인 캐시 응답 모드` 대신 `실제 API 연결됨` 이 뜨면 실제 호출이 나갑니다(요금이 부과됩니다).

> 🔐 **`.env` 는 절대 커밋하지 마세요.** `.gitignore` 에 이미 들어 있습니다.
> 키가 새어 나가면 즉시 발급처에서 폐기(rotate)하세요.

## 자주 겪는 문제

| 증상 | 원인·해결 |
|---|---|
| `NameError: name 'client' is not defined` | 맨 위 **준비 셀**을 실행하지 않았습니다. 노트북은 **위에서부터 순서대로** 실행하세요. |
| `ModuleNotFoundError: openai_client` | 노트북을 일차 폴더 **밖에서** 열었습니다. 폴더째로 열어 주세요. |
| `FileNotFoundError: data/...` | 위와 같은 원인입니다. 작업 폴더가 노트북이 있는 폴더여야 합니다. |
| 답이 `(오프라인 예시 응답입니다)` | 캐시에 없는 요청입니다. 프롬프트를 바꿔 실행한 경우 정상이며, 본인 키를 넣으면 실제 답을 받습니다. |
| `RateLimitError` (429) | 본인 키로 짧은 시간에 많이 호출한 경우입니다. 잠시 뒤 다시 실행하세요. |
| 모델 답이 매번 다르다 | **정상입니다.** 자가채점은 답의 *구조*만 검사합니다. |

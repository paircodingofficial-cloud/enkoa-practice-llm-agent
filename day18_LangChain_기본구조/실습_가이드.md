## 2. 교안_02 — Runnable·Memory·대화 워크플로우

- [ ] **1. Runnable** — 공통 규약(`invoke`·`batch`·`stream`), 스트리밍은 조각을 이어 붙여 다룬다. 퀴즈.
- [ ] **2. RunnableLambda** — 내 함수를 체인 부품으로, 체인과 체인을 한 체인으로(다리 부품).
      따라하기 2개(답 끝 안내 문구 / 다리 놓아 두 체인 잇기)·퀴즈.
- [ ] **3. RunnableParallel** — 한 입력을 동시에 여러 부품에(요약+감정), `RunnablePassthrough`. 따라하기(다른 리뷰)·퀴즈.
- [ ] **4. 대화 기록(Memory)** — 모델은 기억이 없음 실연 → `MessagesPlaceholder` + 기록 리스트. 따라하기(한 턴 더)·퀴즈.
- [ ] **5. 기록 관리** — 누적 함수·최근 N턴 트리밍(순수 함수), `keep_recent(기록, 0)` 함정. 따라하기(최근 1턴)·퀴즈.
- [ ] **6. 장기 기억** — 잘라 낸 사실을 벡터 저장소에 저장(`remember`)하고 질문과 가까운 것만 회상(`recall`).
      따라하기(새 사실 저장·회상)·퀴즈. *(임베딩 모델을 불러오는 데 처음 한 번 시간이 좀 걸립니다.)*
- [ ] **7. 멀티턴 상담 워크플로우** — 역할 프롬프트 + **장기 기억 회상** + 단기 기록(최근 **10턴**) + 체인 종합.
      5단계 질문은 **장기 기억이 없으면 답할 수 없는** 것입니다 — 답에 알레르기 이야기가 들어오는지 확인하세요.
      6단계는 **`input()` 으로 직접 대화**합니다 — `종료` 입력 시 끝나고, `기억해: <사실>` 로 장기 기억에
      바로 저장할 수 있습니다(`while True` + 끝내는 말·최대 턴 수 두 가지 `break`).
      7단계는 12턴을 쌓아도 기록이 **10턴에서 멈추는지**를 모델 없이 확인합니다.

## 3. 과제 LV1 (기초) — 모델·프롬프트·체인

모델이 만든 문장은 **실행할 때마다 달라집니다** — 자가채점은 문장 내용이 아니라 **타입·구조**로 합니다.

- [ ] **1** 모델에게 물어보기(`reply1`·`text1`) · **2** 역할 부여(`messages2`·`text2`)

## 5. 과제 LV3 (통합) — 상담 봇·상품 설명 파이프라인

앞 단계에서 만든 변수를 뒤 단계가 씁니다. 셀을 **순서대로** 실행하세요.

- [ ] **1. 중고거래 상담 봇**(단기+장기 기억) — 1단계 입력 정리·상담 체인(`clean_step`·`counsel_chain`) → 2단계 상담 함수(`ask`·`chat_log`, 최근 **10턴** 유지) → 3단계 첫 질문(`ans_a1`, 기록 2줄) → 4단계 이어 묻기(`ans_a2`, 기록 4줄) → **5단계 장기 기억 확인**(`ans_a3`, 기록 6줄) → **6단계 `while` 멀티턴**(`log_len` = 10)
- [ ] **2. 상품 설명 파이프라인** — 매물 데이터 `used_devices.csv` 로드(`items3`) → 1단계 **파일에서 프롬프트 읽어**(`build_prompt`) 병렬 생성(`gen_parallel`·`gen1`) → 2단계 합성 체인(`pipeline`·`desc2`) → 3단계 일괄 batch(`descs3`, 길이 3) → 4단계 파일 저장(`out_path`, 헤더+3줄)

## 막혔을 때

- 준비 셀에서 **"OPENAI_API_KEY 를 찾지 못했습니다"** 가 나오면: 일차 폴더에 `.env` 가 있는지, 그 안에 본인 키가 채워져 있는지 확인하고 **커널을 재시작**한 뒤 준비 셀부터 다시 실행하세요.
- 모델 호출에서 인증·한도 오류가 나면 키가 유효한지(14일차와 같은 키인지) 확인하세요. `RateLimitError` 는 분당 요청 한도라 잠시 뒤 다시 실행하면 됩니다 — `batch` 는 `config={'max_concurrency': 1}` 을 주면 한 번에 하나씩 보냅니다.
- 모델의 답이 매번 조금씩 달라도 틀린 것이 아닙니다. `temperature=0` 이라 결이 비슷할 뿐 문장이 같지는 않습니다.
- 순수 함수 문제(마스킹·기록 누적·트리밍)는 모델과 무관하니 **입력·출력만** 맞추면 됩니다.
- 체인이 이상하면 파이프 `|` 순서(`프롬프트 → 모델 → 파서`)와 프롬프트 변수 이름을 다시 확인하세요.

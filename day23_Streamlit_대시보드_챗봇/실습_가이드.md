## 막혔을 때

- 앱이 안 뜬다 → 터미널의 빨간 에러 메시지를 읽는다. 대개 오타나 들여쓰기 문제다.
- 값이 자꾸 초기화된다 → `st.session_state` 에 저장했는지 확인 (재실행 모델!)
- 그래프가 안 보인다 → `fig, ax = plt.subplots()` 로 만들고 `st.pyplot(fig)` 에 넘겼는지 확인
- 챗봇/RAG 화면이 안내만 뜨고 멈춘다 → `.streamlit/secrets.toml` 의 `OPENAI_API_KEY` 를 확인한다(파일을 만든 뒤 앱을 다시 실행해야 반영된다).
